                         # starts mid-document with a dangling closing tag).
                         # This was found the hard way: every anchor-based
                         # extraction attempt was silently falling through to
                         # the lower-confidence regex fallback with no error
                         # raised. html.parser has no such issue and needs no
                         # extra dependency, so lxml isn't installed at all.
